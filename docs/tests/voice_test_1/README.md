# Тест колонки № 1 — как запустить

Ничего не создано и не развёрнуто: заводить функцию и навык — только по слову
Алексея (правило проекта). Ниже — что делать, когда он скажет.

1. Отдельная функция, **не трогая `soulledger`**: Cloud Functions → создать
   `curseddemo` в том же каталоге `alicesoulledger` (или в новом — по слову),
   рантайм nodejs22, точка входа `handler.handler`, память 128 МБ,
   таймаут **6 с** (чтобы D5 показал реальный лимит платформы, а не функции),
   приватная. Загрузить `handler.js` (из `docs/tests/voice_test_1/`).
2. Консоль Диалогов → новый **приватный** навык «Тест колонки», backend —
   эта функция. Голос — любой из списка; экран не требовать.
3. Свой звук (A8): «Ресурсы → Звуки» → загрузить короткий файл (MP3/WAV/OGG,
   ≤120 с, ≤5 МБ). Скопировать id, вписать в `IDS.own` в `handler.js`,
   выгрузить новую версию.
4. Картинка (G3): «Ресурсы → Изображения», id в `IDS.image`.
5. Проверка: вкладка «Тестирование» → «паузы». Если работает — на устройстве:
   «Алиса, запусти навык Тест колонки».
6. Результаты — в `TESTS.md`.

**Известные сомнения (заранее):**
- Звуки дверь/меч/сова взяты из прежнего навыка (`alice_soulledger`),
  ни разу не слушались.
- Музыка в библиотеке — ноты, аккорды, барабаны и биты (документация), а не
  мелодии-фон. Тест A5 покажет, чем это можно заменить.
- Шёпот и смена голоса внутри ответа в документации не описаны; A7 — проверка
  без тегов, чисто на слух.
- Заведомо не проверяется здесь: языковая модель (нужны ключи, облако),
  платежи, много игроков вживую.
