# Бета «Таверна» (черновик, локально)

Пошаговая текстовая адвенчура на одной серии: серия 1 «Таверна» из
`docs/story/season1.md`. Игрок пишет действие своими словами, игра разбирает
фразу правилами (без языковой модели). Реплики — черновик; канон не менялся.
На GitHub не опубликовано — ждёт слова Алексея.

Запуск: `python3 -m http.server 8765 --directory docs`, затем
`http://localhost:8765/visual/beta/index.html` (или сервер `board` из
`.claude/launch.json`). Тесты: `node docs/visual/beta/test.js`.

Панель движка (Алексей, 30.09): по каждому ходу — разбор фразы, пропущенные
слова, броски (кубик, модификатор, порог, итог), изменения состояния мира,
журнал ходов с откатом на любой ход, перезапуск сцены (то же или новое зерно).
Кнопка «Скрыть» — играть без панели.

Правила честности (шаг 1, 1.10.2026; тесты — в `test.js`):
- бросок в панели = d20 + модификатор против порога; если по сюжету исход задан,
  строка помечена «по сюжету» (не «провал» и не «крит»); если броска нет — «без броска»
  (подъём сундука Габом, лечение мага); кража кошелька — бросок «тихо ли?»: кошелёк срезан всегда;
- инвентарь и «что у меня» берутся из состояния мира (кошелёк у мечника → у вора);
- оружие из сундука не бьёт; оглушённый капитан сидит; миска, ушедшая капитану, не остаётся в руках;
- арест — выбор: покорность, сопротивление (−2 здоровья), бег, уговоры; «ем вилку» серию не закрывает,
  третье отвлечение — стража теряет терпение (`S.f.arrest` хранит выбор для следующих серий);
- ответ ≤ 1024 знаков: драка начинается следующим ходом после кражи, вход стражи откладывается
  на ход, если ход уже длинный; ввод режется до 300 знаков, очередь «дальше» ≤ 240;
- Эллион по умолчанию ж (решение 30.09); формы по полу проверяются перебором 16 комбинаций полов.
Не сделано (записано в отчёте шага): слух «Проклятый Меч» про человека — ждёт текст от Сценария/Диалогов;
состояние мира 917–1118 Б при пределе Алисы 1 КБ (хранилище — фаза 3); находки 11, 14, 19–35 отчёта теста.

Шаг 2 (1.10.2026; тесты — в `test.js`, раздел «Шаг 2»):
- словарь по `lexicon_wishlist_s1.md`: «заклинание» — существительное, не подпирание; «пинаю», «мяу/мурр», «шепчу» (манера, не «разговоры»),
  «спасибо» ≠ «спасаю», отказ — оператор (`!fight()`), «по-» (поговорю), опечатки в глаголах (≥6 букв, одна ошибка) и существительных;
  новые глаголы resist/yield/order/distract/touch/thanks/kiss, существительные spell/duke/vision; анахронизмы и «нет в сцене» — честный отказ со словом;
- «чтобы…/пока…» — цель, не действие (не исполняется и не уходит в очередь «дальше»); «не откажусь» — согласие;
- арест: терпение 3 хода у каждого героя, три ступени (стражник → Лизард → ведущий, исход «покорность по молчанию», флаг `arrestBy`),
  четыре исхода по смыслу фразы (`arrestKind`), «помощь/осмотр» до двух раз бесплатно; команда 2–4 («1А», `cfg.players`, «Габ бьёт стражника»);
  серия 2 — только `S.f.s2` и заглушка в `rec.notes` («серия 2 — позже»);
- строки с меткой `[ТЕКСТ]` — заглушки беты, слов у Диалогов нет; тексты ареста и вступление Мечника — черновик (пометка в окне игры).

Шаг 3 (1.10.2026; тесты — `test.js`, разделы 3.1–3.5, 535 проверок):
- мечница: «валькирия» у ведущего, «амазонка» у стражи; «силачка», «здоровячка» не звучат;
- заглушки `[ТЕКСТ]` и подсказки в скобках заменены строками Диалогов (≤140, на повтор ≤60); метка `[ТЕКСТ]` осталась только у «подпереть открытой» и «без сознания» (слов нет);
- числа Механик (`rolls.md` §9): открытая подпёртая дверь, «отвлечь» (Дух против 10, +2, подлый удар), сопротивление в аресте = «ранен» (Габ −5, остальные −3; бросок −2, упор −1), капитана и здорового не лечим, книга в серии 1 без броска, 20 и 1 меняют мир, меч Габа d10+2, шок Эллион — флаг;
- репутация у стражи: `S.season.rp` («b3» = ярлык + строгость), в сцене её нет; `S.f.arrest`, `S.f.s2` убраны;
- спутник не погибает до акта III: `hurt()`, метка `ko`, `wake()`; переключатель `COMPANION_MAY_DIE`;
- не сделано: ответы 2–8 «Таверны» по героям (разговоры героев).

Шаг 4 (1.10.2026; тесты — `test.js`, раздел «Шаг 4», всего 709 проверок):
- **Сетка 10×8**, клетка «B4». Клетка занята одним объектом (стол, стойка, сундук C7, миска F3, очаг J7, бочка E1, окно F8 в стене) или одной фигуркой; лавки A1–A5, дверь B8 (проём), «за стойкой» F1–J1 — только хозяин. Расстановка по тексту: Габ A2 спиной к стене у большого стола B1–B2, сундук у двери, миска у стойки, капитан у окна, хозяин у сундука, пока сундук не открыт, потом за стойкой. Расстановка — черновик агента по плану на доске (`locations.html#tavern-plan`).
- **Позиции в состоянии:** `S.c` — 10 знаков (Габ, Эллион, маг, Нобби, хозяин, задира, капитан, три стражника), знак = индекс клетки, `.` — нет на сетке. Это единственная истина; `S.at`/`S.pos[герой]` остались «зоной» (door/corner/bar/hall) для старого движка и всегда равны зоне клетки (проверка в каждом ходе 7 тыс. случайных ходов). Ради места убраны `S.pos.host/lizard/guard`. Старт сцены 923–930 Б (было 935–942), максимум 1307 Б (было 1319).
- **Движение:** «иду к стойке / к сундуку / к очагу / к окну / к двери», «подсаживаюсь к Габу», «прячусь под стол», бег в драке — фишка встаёт в ближайшую свободную клетку рядом с объектом; фигурки друг друга пропускают, встать можно только в свободную. Отказ текстом (оружие у двери, «уйти до конца вечера») — фишка стоит. Цена клетки — `CS.Grid.MOVE.costPerStep` (0, решат Механики). Путь хода — `rec.moves`, в панели движка раздел «4. Карта: клетки и путь»; на карте — пунктир.
- **По сюжету** (герой без игрока и NPC): маг подсаживается к Габу, хозяин уходит за стойку, Эллион к стойке и задира к ней, Нобби к задире; арест: стражники входят по одному (первый в дверях, дальше каждый ход шаг к героям и входит следующий), решение героя двигает фишку (бег — к двери/окну/столу, бросок — к стражнику, уговоры — к капитану, покорность — на месте).
- **Откат и перезапуск** возвращают клетки (позиции — часть `S`).
- **Фигурки** (8, обе формы по полу у героев): Габ/Габриэла 190, Эллион 180, Луциан/Луциания 170, Нобби 150, хозяин 170, задира 182, капитан Лизард 178 (человек, усы, мундир), стража 178. Рост хозяина, задиры, Лизарда и стражи каноном не задан — подобран под сцену. Метки: «ранен» (здоровье ≤ ⅔, `states.md`), «оглушён» (капитан/задира сидят), «под столом» (`S.hidden`). Герой без сознания (`ko`) с карты уходит, как раньше.
- Не сделано: ответы 2–8 «Таверны» по героям и находки 56–68 (шаг 5); героев-оглушённых (ko) на карте нет; в драке фишки стоят на местах (правил движения нет).
