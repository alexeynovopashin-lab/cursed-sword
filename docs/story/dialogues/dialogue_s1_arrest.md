## Как читать

- **Ответ** — то, что колонка говорит за один раз (≤1024 знаков, цель 700).
- **Строка** с пометкой `≤140`, `≤60` и т. п. — кусок, который Бета вставляет в
  ответ; число — предел знаков вместе с произнесённым именем говорящего.
  `шутка` — в строке шутка ведущего; в одном ответе такая строка одна.
- Имя говорящего колонка произносит перед его репликой («Лизард: …»);
  «Ведущий» не произносится. Несколько говорящих в одной строке — по очереди.
- Формы по полу: `{Г:м|ж}` — Габ, `{Э:м|ж}` — Эллион, `{Л:м|ж}` — маг, `{Н:м|ж}` —
  Нобби, `{П:м|ж}` — герой, о котором строка (в одиночной игре — герой игрока).
  `за Нобби` — строка только для этого героя. По умолчанию Габ м, Эллион ж,
  маг м, Нобби м. Метки подставляются до отправки в Алису, вслух их нет.
- Счёт — `dialogue_s1_arrest_count.py` рядом: читает этот файл, перебирает
  16 сочетаний пола × 4 героя игрока. «До» — прогон беты
  `dialogue_s1_arrest_before.js` (бета `f719516`, зерно 11; код читает, не правит).

> нигде нет. Их вещи остаются в сундуке у двери, но сейчас не до вещей. [строка
> исхода] Решётка лязгает. Кошелёк так и лежит у Вора за пазухой. Где-то наверху
