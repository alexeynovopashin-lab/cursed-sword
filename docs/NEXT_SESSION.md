## Канон, который держать (коротко; полностью — скелет и «библия»)

- 12+, тёмный юмор «Вокс Макины» без мата и пошлости; романтика без секса.
- Четыре героя по два навыка; пол и имя выбирает игрок. По умолчанию: мечник Габриэль/Габриэла, лучник Ивар (Эллион), маг Луциан/Луциания, вор Нобби.
- Кольцо: маг зависит от мечника → мечник западает на лучника → лучник хочет отплатить вору → вор хочет украсть книгу мага.
- Винтербург: таверна → драка → арест → «герцог»-доппельгангер шлёт в Даркгрот за короной. Подсказок про двойника нет; «Бернара» выдают привычки настоящего.
- Меч наставника Бернара. Правила: меч не умирает, пока жив владелец; владелец не умирает, пока рядом спутники и меч; меч переходит к ближайшему, когда владелец отказался; меч берёт удачу спутников только когда владельцу грозит смерть.
- **Тайна меча не раскрывается до акта III** (скелет §4а).
- Финал: мечник умирает на минуту, маг возвращает. Итог — отряд стал семьёй.
