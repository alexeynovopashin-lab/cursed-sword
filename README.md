# Проклятый меч

Рабочее название. Кооперативное голосовое фэнтези-приключение для Алисы:
1–4 игрока на одной колонке, история в виде сериала (серии, арки, сезоны), с
ориентиром на «Легенду о Вокс Макине»: D&D внутри, сюжет снаружи.

Вырос из навыка «Склеп Плачущей Тени» (`alice_soulledger`), когда тесты на
колонке показали, что игра с тайными целями голосом не работает, а играть
хочется командой (`DECISIONS.md`).

## Документы

- `DECISIONS.md` — что решено, словами Алексея.
- `ROADMAP.md` — фазы, что сделано, что дальше, открытые вопросы.
- `docs/story/through_line.md` — сквозной сюжет (утверждён 26.09).
- `docs/story/bible.md` — «библия» мира: герои, места, меч, злодей.
- `docs/ideas/` — сырые идеи и обсуждения, не решения.
- `ITERATIONS.md` — итерации: что делаем сейчас и дальше, по шагам.
- `docs/NEXT_SESSION.md` — состояние проекта для новой сессии.
- `docs/orchestrator_project_instructions.md` — инструкции оркестратора.
- `SESSIONS_CHAT.md` — чат сессий (не в git; до 27.09 жил в `ws:30_agents/`).
