# Проверка текста сцены — `check_text.py`

Ведёт Литератор. Это подсказка для глаза, а не судья: скрипт выдаёт кандидатов, решение
принимает человек. Только читает файлы.

```
python3 docs/story/tools/check_text.py docs/story/dialogues/<сцена>.md
python3 docs/story/tools/check_text.py --g ж <сцена>.md    # подставить женские формы меток
python3 docs/story/tools/check_text.py --selftest           # каждая проверка срабатывает и молчит, где надо
```

Формат сцены — как в `docs/story/dialogues/`: заголовок «## Ответ N …» (или «**Ответ N**»),
под ним пункты «- [теги ·] **Говорящий:** текст», метки по полу `{Г:м|ж}`. Имя говорящего
колонка произносит, поэтому скрипт считает его словом реплики.

## Что проверяет

| № | Проверка | Как, без морфологии | Известные ложные срабатывания |
|---|---|---|---|
| 1 | «ты» и «вы» у одного говорящего — в реплике и в ответе | местоимения; 2-е лицо на -ешь/-ишь; повелительное на -ай/-яй и по списку («иди», «спроси»…); «вы» на -йте/-ьте/-ите | «вы» группе и «ты» одному («Следующие!… не забудьте» / «Клади»); у ведущего между репликами не ловит (он законно говорит столу «вы», игроку «ты») |
| 2 | повтор слова или корня в одном предложении, в соседних и через одно | основа слова — стеммер Портера (Snowball), служебные слова отброшены | нарочные повторы: перепалка «ответ на слово», рефрен, игра слов |
| 3 | предложение длиннее 15 слов (`--max N`) | счёт слов | — |
| 4 | одно начало у фраз (2 из 3 подряд); имя на стыке «…Это Луциан. Луциан: …» | первое слово, основа | повтор слова собеседника в перепалке |
| 5 | точка зрения: «вы» по месту («за вашей спиной», «на ваши пояса») и герой отряда третьим лицом в словах ведущего одного ответа | регулярка «предлог + ваш/вас» и имена героев или метки | — |
| 6 | формы по полу: имя героя без метки; «я/ты + прошедшее» без метки; мужская форма в предложении с меткой; фраза с глагола без подлежащего («Был наёмником»); мужская форма в следующей реплике («такой… пригодился») | окончания -л/-лся, -ый/-ий, список на -ой | «Кто с ним пошёл, тот не вернулся»; «пустой круг» рядом с меткой |
| 7 | омографы без ударения («стоит», «замок», «мука»…) | список; ударение в Алисе — «+» перед гласной | список короткий, пополнять |

## Чего не ловит (работа глазами)

- Падеж и согласование без меток («кружку… они», «Знаки не выдаю» вместо «Знаков»).
- Управление («греться к очагу» без «иди»).
- Порядок слов («в отряд такой»).
- Порядок действий и логику вещей («шатается лавка — держат стол»).
- Разные основы одного корня: «усатый / усами».
- Название, которое на слух не название.
- Погружение, тон, шутки.

(DECISIONS 1.10). Что она добавит: согласование прилагательного с существительным,
падеж при «не», точное повелительное наклонение и 2-е лицо, общий корень у «усатый /
усами». Пока её нет, проверки 1, 2 и 6 работают по окончаниям.
