## Краткое содержание разговора с GPT (не слова Алексея)

- Жанр: кооперативное голосовое фэнтези-приключение; D&D — внутренняя ДНК, не интерфейс.
- Цикл: идём → исследуем → находим → рискуем → сражаемся → последствия → сильнее → глубже.
- Бой: щит (безопасно) и контратака (рискованно, с ответным ударом) вместо
  «защитить / принять удар»; учить через пролог с наставником, не инструкцией.
- Без HP: состояния (здоров, ранен, тяжело ранен, при смерти; проклят, отравлен…).
- Артефакт не усиливает, а «делает мир больше»: кольцо шёпота, око подземелья,
  маска мёртвых, меч наставника, который дрожит рядом с тем, что его забрало.
- Карта на бумаге — механика; комнаты повторяются, «мы здесь уже были».
- Этажи: слизь/крысы/гоблины → скелеты/мимики/иллюзии → культисты/NPC → следы наставника.
- Сундук-мимик: первые два настоящие, третий говорит «Наконец-то».
- Сюжет из флагов мира, а не бинарных веток; NPC-спутник может стать персонажем второго игрока.
- 1–4 игрока, каждый — свой герой; скрытые цели старой версии — поздний слой.
- Сезон 1: Ученик → Таверна → Дорога → Первый этаж → Сундук → Артефакт → След →
  … → босс, наставник стал частью подземелья. «Склеп Плачущей Тени» — поздняя арка.
- Выбор героя — короткая сцена, а не экран классов.

## Идея Алексея: комната-ловушка с пауками и водой (2026-09-26, пересказ близко к тексту)

Группа входит в комнату 10×10 клеток, осматривается: два сундука, одна дверь,
окно в потолке с решёткой, скелет, по которому ползает паук, факел на стене.

Способности, полученные до этой комнаты (у каждого свои):
- **Вор** — поиск тайников и скрытых лазов.
- **Лучница** — стрела с верёвкой для перемещения («большая свобода действий»);
  залп по площади: урон одной стрелы 5, при 5 стрелах урон делится (по 1);
  подожжённая стрела — радиус 5 клеток и освещает помещение.
- **Маг** — урон по площади 25×25 клеток.
- **Воин** — перчатки Рихтера: удар по площади, сбивает с ног при броске больше 10,
  иначе слабый урон −1.

Ход событий:
1. Вор видит скрытые рычаги, нажимает один — с потолка сыплются пауки, 100 штук.
   По одному слабые, вместе наносят колоссальный урон.
2. Все бьют по площади, остаётся 25 пауков. Рой — как один монстр: урон равен
   числу пауков, занимает большую площадь; убивать по одному не вариант.
3. Пауки облепили героев. В свете стрел вор замечает ещё один переключатель,
   прыгает, нажимает — дверь замуровывается, комната заливается водой.
4. 50 секунд на раздумье, много вариантов спастись, воды всё больше. Горящая стрела
   показала решётку на потолке: маг бьёт с вероятностью и разбивает её; лучница
   стреляет — стрела не цепляется.
5. Все, кроме воина, всплывают. Воин в тяжёлых доспехах: снимает их и всплывает,
   теряет щит и доспехи — он больше не танк. Если догадается попросить верёвку —
   может нырнуть за доспехами.

«Я не думаю что нам нужна система клеток и статов, но игра может их учитывать
"под капотом"».
